# Playground

This is a practice repository for new members of [Makvion Technologies](https://github.com/Makvion-Technologies).

It is a safe place to practise Git and GitHub: cloning, branches, commits, and pull requests. Nothing here is a product, and this repository is not connected to any hosting service.

## First-day exercise

If you are new, follow the members-only [onboarding guide](https://github.com/Makvion-Technologies/.github-private/blob/main/ONBOARDING.md) (you must be signed in as a member to open that page).

The short version:

1. Do **not** fork this repository. Clone it, then create a branch from `main`, for example `docs/add-yourusername`.
2. Add a file at `members/yourusername.md` (use your GitHub username as the file name).
3. Commit with a message such as `docs: add yourusername to members`, push the branch, and open a pull request into `main`.
4. Request a review from your lead, then wait. Do not push to `main` yourself.

See `members/README.md` for the file format, and [CONTRIBUTING.md](CONTRIBUTING.md) for the usual branch and pull request rules.

## What this repository is not

Please do not use the playground for product work, secrets, or large experiments that belong in another repository. If you are unsure, ask your lead.
