# Members

Each new member adds one file in this folder, named after their GitHub username, as their first pull request.

## File name

`members/yourusername.md`

Examples: `members/priyasharma.md`, `members/rahul-patil.md`.

Use your exact GitHub username so we can match the file to your account.

## Suggested contents

```markdown
# Your Name

- GitHub: @yourusername
- Role: Engineering intern (or the title your lead gave you)

Hello, I am looking forward to working with the team.
```

You may add a short professional sentence or two. Do not put phone numbers, personal email addresses, or any secrets in this file.

Add the file on a branch, not on `main`, and open a pull request.
