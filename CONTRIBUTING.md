# Contributing

This is a practice repository. The same rules we use on product repositories apply here, so you can learn them safely.

## Do not fork

Clone this repository directly, create a branch, and open a pull request into `main`.

## Branches

Create your branch from the latest `main`:

- `docs/add-yourusername` — for the first-day member file
- `feat/`, `fix/`, `chore/`, or `docs/` prefixes for any later practice

## Commits

Use a short, professional, conventional message, for example:

```
docs: add priyasharma to members
```

## Pull requests

Open a pull request against `main`. Fill in the template. Request a review from your lead. New members are not reviewers.

`main` is protected: a pull request, one approval, and resolved conversations are required. You cannot force-push or delete `main`.

## Never commit

Do not add `.env` files, API keys, credentials, or AI tool files such as `CLAUDE.md` or `AGENTS.md`.
